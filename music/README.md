# Background Music for Video Clips

Drop royalty-free MP3 files here. The video editor will mix them at ~15% volume beneath the speech.

## Required filenames

| File | Style | Best for |
|------|-------|----------|
| `upbeat.mp3` | Energetic, motivational | Product demos, tips, announcements |
| `calm.mp3` | Soft, ambient | Thought-leadership, reflective content |
| `cinematic.mp3` | Dramatic, orchestral | Brand story, founder intro, emotional content |

## Where to get free tracks

- **Pixabay Music** — pixabay.com/music (free, no attribution needed)
- **Free Music Archive** — freemusicarchive.org (check license per track)
- **YouTube Audio Library** — studio.youtube.com → Audio Library (free for any use)
- **Bensound** — bensound.com (free with attribution)

## Tips

- Use tracks 60–120 seconds long (they loop automatically for longer clips)
- Instrumental only — the system mixes at 15% so speech stays audible
- MP3 format, 128kbps or higher
